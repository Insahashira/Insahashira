## 🚀 Featured Projects  

### 🩺 EmoAI – Healthcare Communication AI Web Application  
AI-powered system designed to address communication gaps in multilingual medical settings.

- Designed a 4-stage AI pipeline (speech recognition → translation → emotion analysis → storage)
- Integrated Whisper for speech recognition and DeepFace for facial emotion analysis
- Developed RESTful APIs using FastAPI
- Structured and managed speech data storage using MongoDB
- Currently improving emotion classification performance through model refinement and evaluation

### ✈️ Flight Reservation Database System  
Relational database system simulating airline reservation workflows.

- Designed ER diagram and normalized relational schema (15+ tables)
- Implemented composite primary keys and foreign key constraints
- Developed complex SQL queries with multi-table joins for reservation processing and flight search
- Ensured referential integrity and validation rules for system reliability

### 🖐️ ReChord – Gamified Hand Rehabilitation System
Real-time, client-side hand rehabilitation game built for competitive development.
- Awarded CS Prize at the 3rd Annual SFM Health Innovation Challenge
- Developed a real-time, client-side hand rehabilitation game using MediaPipe Tasks Vision
- Resolved jitter and scale variance through custom anchor logic
- Drove a spec-driven workflow with a shared steering file across agents, delivering a working product in under 3 hours of a 5.5-hour competition

### ✋ PinchPinch – Real-Time Gesture Recognition Library
Privacy-conscious gesture recognition library for real-time hand tracking.
- Designed and implemented a MediaPipe + OpenCV gesture recognition library with a privacy-conscious pipeline that discards raw frames after landmark extraction
- Architected a multi-component pipeline (TrackerConfig → HandTracker → MotionExtractor → GestureClassifier)
- Structured development around spec-driven steering files for agentic workflows
